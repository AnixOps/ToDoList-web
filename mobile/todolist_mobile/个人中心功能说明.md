# 个人中心（我的）功能说明

## 功能概览

个人中心是用户管理个人信息、查看统计数据、设置应用偏好的核心页面。

## 主要功能模块

### 1. 用户信息头部 ✅
- **展开式AppBar**：优雅的渐变色背景
- **用户头像**：显示用户名首字母
- **用户名**：显示当前登录用户名
- **邮箱**：显示用户邮箱地址

### 2. 统计数据卡片 ✅
展示用户的待办事项完成情况：

#### 第一行统计
- **总事件**：所有创建的大事件数量
- **已完成**：已完成的事件数量（绿色）
- **进行中**：待完成的事件数量（橙色）

#### 第二行统计
- **已过期**：已过期的事件数量（红色）
- **总任务**：所有任务总数（包括子任务）
- **完成率**：任务完成百分比（动态计算）

### 3. 账户设置 ✅

#### 编辑个人资料 🚧
- 功能：修改用户名、邮箱等信息
- 状态：开发中

#### 修改密码 🚧
- 功能：更新账户密码
- 状态：开发中

### 4. 应用设置 ✅

#### 在线/离线模式切换 ✅
- **功能**：切换数据存储模式
  - 在线模式：数据同步到服务器
  - 离线模式：数据仅保存在本地
- **交互**：Switch开关，实时切换
- **状态提示**：切换后显示成功消息

#### 同步数据 ✅
- **功能**：手动触发数据同步
- **条件**：仅在线模式可用
- **状态**：显示加载动画
- **反馈**：同步成功/失败提示

#### 语言设置 🚧
- 功能：中文/English切换
- 状态：开发中

#### 通知设置 🚧
- 功能：管理推送通知
- 状态：开发中

### 5. 数据管理 🚧

#### 导出数据 🚧
- 功能：导出所有待办事项数据（JSON/CSV格式）
- 状态：开发中

#### 导入数据 🚧
- 功能：从文件导入数据
- 状态：开发中

#### 清除缓存 🚧
- 功能：清除本地缓存数据
- 交互：确认对话框
- 状态：开发中

### 6. 关于 ✅

#### 关于应用 ✅
- 显示应用名称、版本号
- 应用描述和功能介绍
- 使用showAboutDialog

#### 帮助与反馈 🚧
- 功能：用户帮助和反馈收集
- 状态：开发中

#### 隐私政策 🚧
- 功能：显示隐私政策内容
- 状态：开发中

### 7. 退出登录 ✅
- **功能**：退出当前账户
- **交互**：确认对话框
- **操作**：

## 数据流程

### 1. 统计数据计算
```dart
// 事件统计
final totalEvents = events.length;
final completedEvents = events.where((e) => e.isCompleted).length;
final pendingEvents = events.where((e) => !e.isCompleted).length;
final overdueEvents = events.where((e) => e.isOverdue).length;

// 任务统计
for (final event in events) {
  totalTasks += event.tasks?.length ?? 0;
  completedTasks += event.tasks
      ?.where((t) => t.status == TaskStatus.completed)
      .length ?? 0;
}

// 完成率
final completionRate = totalTasks > 0 
    ? (completedTasks / totalTasks * 100)
    : 0;
```

### 2. 模式切换流程
```
用户点击开关
    ↓
调用 TodoProvider.switchMode(offline: bool)
    ↓
更新 _isOfflineMode 标志
    ↓
调用 OfflineStorageService.setOfflineMode()
    ↓
重新加载数据 loadEvents()
    ↓
notifyListeners() 刷新UI
    ↓
显示成功/失败消息
```

### 3. 数据同步流程
```
用户点击"同步数据"
    ↓
检查是否在线模式
    ↓
调用 TodoProvider.syncData()
    ↓
SyncService.performFullSync()
    ↓
上传本地未同步数据
    ↓
下载服务器最新数据
    ↓
合并冲突
    ↓
更新本地数据库
    ↓
重新加载 loadEvents()
    ↓
显示同步结果
```

## 性能优化

### 1. 懒加载
- 统计数据在页面初始化后加载
- 使用`addPostFrameCallback`避免阻塞渲染

### 2. 状态管理
- 使用`Consumer`仅重建需要更新的部分
- 统计数据实时计算，不额外存储

### 3. 用户体验
- 操作有明确的加载状态
- 所有异步操作都有错误处理
- 友好的错误提示信息
