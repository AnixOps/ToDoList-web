# 二级任务系统说明

## 数据结构

### 第一级：TodoEvent（大事件/事件）
- 在主列表页面（TodoListScreen）显示
- 每个Event是一个卡片，显示标题、描述、截止日期等
- 点击Event卡片会跳转到TaskDetailScreen

### 第二级：TodoTask（任务）
- 在任务详情页面（TaskDetailScreen）显示
- 每个Event下面可以有多个Task
- Task分为两类：
  - **父任务**（parentTaskId = null）：顶级任务
  - **子任务**（parentTaskId = 父任务的id）：父任务下的子任务

## 数据模型关系

```
TodoEvent（大事件）
├── TodoTask 1（父任务）
│   ├── TodoTask 1.1（子任务）
│   ├── TodoTask 1.2（子任务）
│   └── TodoTask 1.3（子任务）
├── TodoTask 2（父任务）
│   ├── TodoTask 2.1（子任务）
│   └── TodoTask 2.2（子任务）
└── TodoTask 3（父任务）
    └── TodoTask 3.1（子任务）
```

## 用户操作流程

### 1. 创建事件（第一级）
1. 在主页面点击右下角的 + 按钮
2. 填写事件信息（标题、描述、优先级、截止日期）
3. 保存后事件出现在主列表

### 2. 查看事件详情
1. 点击任意事件卡片
2. 进入TaskDetailScreen
3. 看到事件信息和该事件下的所有任务

### 3. 添加父任务（第二级 - 顶层）
1. 在TaskDetailScreen中点击右下角的 + 按钮
2. 或者在空白时点击"添加第一个任务"按钮
3. 填写任务信息（标题、描述、优先级、截止日期）
4. 这个任务的`parentTaskId`为null，是顶级任务

### 4. 添加子任务（第二级 - 子层）
1. 在父任务右侧点击 + 图标
2. 或者在任务选项菜单中选择"添加子任务"
3. 填写子任务信息
4. 这个任务的`parentTaskId`设置为父任务的id

## 数据库结构

### events表（事件）
- id (主键)
- title（标题）
- description（描述）
- user_id（用户ID）
- created_at, updated_at
- due_date（截止日期）
- is_completed（是否完成）
- priority（优先级）

### tasks表（任务）
- id (主键)
- event_id（所属事件ID，外键）
- parent_task_id（父任务ID，null表示顶级任务）
- title（标题）
- description（描述）
- user_id（用户ID）
- created_at, updated_at
- due_date（截止日期）
- status（状态：pending/completed）
- priority（优先级）
- sort_order（排序）
