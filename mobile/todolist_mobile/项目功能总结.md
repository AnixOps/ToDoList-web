# TodoList Mobile - 完整功能总结

## 项目概述

一个功能完善的Flutter待办事项管理应用，支持二级任务管理、离线模式、数据同步等核心功能。

## 技术栈

- **框架**：Flutter 3.x
- **状态管理**：Provider
- **本地存储**：
  - Web: localStorage
  - Mobile: SQLite (sqflite)
- **网络请求**：http
- **国际化**：intl + ARB文件
- **路由管理**：go_router
- **UI组件**：Material Design 3

## 数据模型

### TodoEvent（事件）
```dart
class TodoEvent {
  final int id;
  final String title;
  final String description;
  final int userId;
  final DateTime createdAt;
  final DateTime updatedAt;
  final DateTime? dueDate;
  final bool isCompleted;
  final TaskPriority priority;
  final List<TodoTask>? tasks;
}
```

### TodoTask（任务）
```dart
class TodoTask {
  final int id;
  final String title;
  final String description;
  final int eventId;
  final int? parentTaskId;      // 父任务ID，null表示顶级任务
  final int userId;
  final DateTime createdAt;
  final DateTime updatedAt;
  final DateTime? dueDate;
  final TaskStatus status;
  final TaskPriority priority;
  final int sortOrder;
  final List<TodoTask>? subTasks;
}
```

## 状态管理流程

### 创建任务流程
```
用户操作
    ↓
UI触发 → Provider方法
    ↓
判断模式（在线/离线）
    ↓
在线：API请求 → 服务器存储 → 返回数据
    ↓
离线：本地数据库 → 保存数据
    ↓
更新内存状态
    ↓
notifyListeners()
    ↓
UI自动刷新
```

### 数据同步流程
```
触发同步
    ↓
获取本地未同步数据
    ↓
批量上传到服务器
    ↓
下载服务器最新数据
    ↓
比较时间戳解决冲突
    ↓
更新本地数据库
    ↓
刷新内存状态
    ↓
同步完成
```
