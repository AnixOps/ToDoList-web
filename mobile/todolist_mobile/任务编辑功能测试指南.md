## 测试步骤

### 场景1：编辑父任务

1. **打开应用并创建事件**
   - 在主页点击 + 按钮
   - 创建事件"测试项目"

2. **添加父任务**
   - 进入"测试项目"详情页
   - 点击 + 按钮
   - 添加任务"需求分析"
   - 优先级：中
   - 截止日期：明天

3. **编辑父任务**
   - 点击"需求分析"任务
   - 在弹出的菜单中选择"编辑"
   - 修改标题为"需求分析与设计"
   - 修改优先级为"高"
   - 修改截止日期为后天
   - 点击"保存"

4. **验证结果**
   - ✅ 应该显示绿色提示"任务更新成功"
   - ✅ 任务标题应该变为"需求分析与设计"
   - ✅ 优先级标签应该显示为红色"高"
   - ✅ 截止日期应该显示为"2天后"

### 场景2：编辑子任务

1. **为父任务添加子任务**
   - 点击"需求分析与设计"任务右侧的 + 图标
   - 添加子任务"收集用户需求"
   - 添加子任务"绘制原型图"

2. **编辑子任务**
   - 点击子任务"收集用户需求"
   - 选择"编辑"
   - 修改标题为"收集并整理用户需求"
   - 添加描述："访谈至少10个用户"
   - 点击"保存"

3. **验证结果**
   - ✅ 子任务标题应该更新
   - ✅ 子任务依然保持缩进显示
   - ✅ 父子关系没有改变

### 场景3：修改任务状态

1. **编辑任务完成状态**
   - 点击任务的复选框可以切换完成/未完成
   - 或者在编辑对话框中修改

2. **验证进度更新**
   - ✅ 顶部进度条应该自动更新

## 可能遇到的问题及解决方案

### 问题1：点击编辑没有反应
**原因：** EditTaskDialog组件没有正确导入
**解决：** 
- 检查`task_detail_screen.dart`是否导入了`edit_task_dialog.dart`
- 确认`_editTask()`方法已实现

### 问题2：保存后没有更新
**原因：** Provider状态没有通知UI刷新
**解决：**
```dart
// TodoProvider.updateTask方法末尾应该调用
notifyListeners();
```

### 问题3：离线模式无法保存
**原因：** Web存储服务的updateTask实现问题
**检查：**
```dart
// web_storage_service.dart中的updateTask方法
Future<bool> updateTask(TodoTask task) async {
  // 应该更新localStorage
  _localStorage[_tasksKey] = tasksJson;
  return true;
}
```

### 问题4：API调用失败
**原因：** 后端API不支持或URL错误
**检查：**
1. 查看浏览器控制台的网络请求
2. 确认API端点：`PUT /api/tasks/{id}`
3. 检查请求体格式是否正确
